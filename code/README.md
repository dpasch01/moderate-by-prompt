# Code

The evaluation and analysis code will be released here upon acceptance. It covers data preparation, the model runners for all tasks and conditions, the decomposition rules, the threshold control, timing, the paired cluster bootstrap, the cascade simulation, and figure generation.

The material in this repository (prompts, model interfaces, settings, and results) is sufficient to reimplement the evaluation in the meantime.

## Datasets

The datasets are not redistributed. Obtain them from their original sources under their terms of use:

- Dynamic: Vidgen et al. (2021), Dynamically Generated Hate Speech Dataset.
- Measuring Hate Speech: Sachdeva et al. (2022).
- HateXplain: Mathew et al. (2021).
- HateCheck: Röttger et al. (2021).
